# ✨ واجهة متجر ركن السعادة (Rokn El-Saada Storefront)

مرحباً بك في مستودع الكود البرمجي الخاص بالواجهة الأمامية وتجربة المستخدم لمتجر **ركن السعادة** 🛍️. تم تصميم وتطوير هذه الواجهة البصرية الأنيقة باستخدام مكتبة **React.js** وأحدث أدوات البناء **Vite** لتوفير تجربة تسوق إلكتروني متكاملة، تفاعلية، وسريعة للغاية، تمتاز بالأناقة والبساطة البصرية لتليق بزوار وعملاء متجرنا.

---

## 🎨 الرؤية وتجربة المستخدم (User Experience & Design)

تم بناء التصميم البصري لمتجر ركن السعادة بالاعتماد على دراسات تجربة المستخدم الحديثة وسلوك المستهلك الرقمي:
* **التصميم المتجاوب بالكامل (Mobile-First Responsive Design)**: واجهة تسوق ذكية تتكيف وتتطابق مع شاشات الهواتف المحمولة بامتياز تتيح استعراض السلة والطلب وحفظ الأمنيات بسهولة فائقة، وتتكامل بسلاسة مع شاشات الأجهزة اللوحية والحواسب المكتبية.
* **الهوية البصرية المتناسقة**: استخدام لوحة ألوان دافئة وراقية ممزوجة بلمسات جذابة تتناسب مع المنتجات الفاخرة مثل العطور والإكسسوارات الفنية.
* **التفاعل اللحظي والمؤثرات الدقيقة (Micro-interactions)**: تم استخدام تأثيرات الانتقال البصرية الأنيقة عند التمرير وحركات النوافذ المنبثقة التفاعلية لإعطاء إحساس بالحيوية والجاذبية للواجهة.

---

## ⚡ الميزات والخصائص التفاعلية للمشتري

1. **تصفح واستكشاف المنتجات**:
   * عرض واجهات تفاعلية جذابة للمنتجات (المنتجات الأكثر مبيعاً، المنتجات الواصلة حديثاً).
   * إمكانية فتح صفحة المنتج بالتفصيل لرؤية الوصف، الصور المتعددة، واختيار المقاس المطلوب بمرونة عالية.

2. **نظام فلاتر البحث والفرز المتقدم**:
   * فلترة المنتجات حسب القسم الفرعي.
   * فلترة ديناميكية ذكية للأسعار (تحديد نطاق سعري مسبق أو مخصص).
   * فرز فوري للمنتجات (حسب الأحدث، حسب السعر من الأقل للأعلى، وحسب السعر من الأعلى للأقل).

3. **سلة المشتريات وقائمة الأمنيات (Cart & Wishlist Flows)**:
   * **سلة المشتريات**: تفاعلية بالكامل، تتيح للمشتري إضافة وتعديل كميات المنتجات فورياً مع احتساب المجاميع التفصيلية تلقائياً.
   * **قائمة الأمنيات**: تتيح للمستخدم حفظ المنتجات المفضلة لديه بلمسة زر والعودة إليها لاحقاً لشراءها مع حفظها بذاكرة المتصفح.

4. **إتمام الطلب السلس والدفع الذكي**:
   * إدخال تفاصيل الشحن والعميل بدقة في واجهة مصممة لتسهيل الإدخال.
   * دعم طرق الدفع المفضلة محلياً (الدفع عند الاستلام، فودافون كاش، انستا باي).
   * واجهة ذكية تتيح للعملاء رفع وإرفاق صورة "إثبات تحويل الأموال" مباشرة عند اختيار الدفع الإلكتروني لتسريع عملية مراجعة وتأكيد الطلبات من قبل الإدارة.

5. **لوحة تحكم الإدارة والمراقبة (Premium Admin Dashboard)**:
   * لوحة معلومات متطورة تمنح الإدارة تقارير وإحصائيات مبيعات لحظية.
   * تتبع دقيق للفواتير وحالة الدفع وإمكانية ترقية حالة الطلبات (Pending, Shipped, Delivered) وتأكيد الدفعات المالية.
   * إدارة كاملة للمنتجات، الأقسام، والكوبونات الترويجية الفعالة.

## 🛠️ التقنيات والمكتبات المستخدمة (Frontend Stack)

* **React.js & Vite**: كأساس بريموم لبناء واجهة تفاعلية خفيفة الوزن وسريعة التحميل بالاعتماد على خوارزميات الـ Virtual DOM.
* **Tailwind CSS**: لبناء التصميم العصري والمتجاوب بكفاءة عالية وألوان متناغمة.
* **Context API (React)**: لإدارة الحالة المشتركة للتطبيق بالكامل (إدارة هوية المستخدم، سلة المشتريات، وقائمة الأمنيات).
* **Axios**: للاتصال الآمن وسلس بالواجهة الخلفية لإجراء استعلامات وتحديثات البيانات بشكل غير متزامن.
* **Lucide React**: حزمة أيقونات مرسومة بدقة وعصرية تضيف لمسة جمالية للواجهة.
* **SweetAlert2 & React Hot Toast**: لإظهار التنبيهات اللحظية والتفاعلية للمستخدمين بشكل عصري ممتع.

## 🚀 تشغيل الواجهة محلياً (How to Run Locally)

تأكد من تنصيب بيئة **Node.js** على جهازك، ثم اتبع الخطوات البسيطة التالية:

1. قم بتثبيت الحزم البرمجية المعتمدة للمشروع:
   ```bash
   npm install
   ```

2. قم بتشغيل خادم التطوير والتصفح المحلي:
   ```bash
   npm run dev
   ```

3. سيقوم Vite بتشغيل خادم التطوير فوراً وسيعطيك الرابط المحلي للتصفح وتجربة المتجر.
